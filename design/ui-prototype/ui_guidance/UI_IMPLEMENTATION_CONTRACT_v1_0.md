## Current presentation contract

Design revision 8 applies the same visual language across all 58 registered views and 13 primary destinations. Navigation, page headings, resource types, primary actions, states and recent activity use shared icons with visible labels. Provider placement, runtime health, evidence qualification, authorization and billing remain distinct. Recent activity identifies the affected object, actor and actor kind, recorded time, disposition and useful review link. Requested, recorded and confirmed outcomes are not interchangeable.

The feed is illustrative and incomplete. Its strict display schema and source map use existing audit and workload records; no new activity table or canonical HTTP endpoint is introduced. A live authorized projection, disclosure filtering before pagination and real network-state behavior still require implementation and testing. VISUAL_SYSTEM_GUIDE_v1_0.md and ACTIVITY_DATA_MAP.json in ui_workloads define the current presentation contract. The nine technical and disclosure pairs retain their architecture baseline; this visual revision supersedes their earlier UI presentation references without changing formal requirements or claims.

Dependency workspaces show service-only, agent-only and combined views over a shared illustrative topology, including cloud resources. The Northstar Payments fixture is API-shaped UI sample data only; it is not seeded into a provider adapter or accepted by S06. A live UI must request an explicit authorized graph revision from S06. S03 discovers provider resources, S04 qualifies source evidence, and S06 accepts and verifies graph revisions before they are used for decisions.
