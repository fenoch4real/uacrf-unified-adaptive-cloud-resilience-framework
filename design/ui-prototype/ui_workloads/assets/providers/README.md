# Cloud provider marks

The GCP, AWS and Azure marks are included locally from the pinned [Devicon v2.17.0 source](https://github.com/devicons/devicon/tree/v2.17.0/icons). See LICENSE.txt for the collection license. Provider marks identify illustrative cloud context; they do not establish connection health, endorsement, deployed resources or recovery independence. No external icon request is needed when opening this package.
