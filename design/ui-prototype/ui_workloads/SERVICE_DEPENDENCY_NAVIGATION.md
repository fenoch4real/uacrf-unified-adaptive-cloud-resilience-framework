# Service dependency navigation

Version 1.0 · UI design revision 8 · Alignment revision 22 · Guide revision 5

Dependencies now exposes Service dependencies as its first submenu link, alongside Agent dependency graph and Model dependencies. The service entry opens the existing UI-18 service-only Checkout graph. The parent Dependencies link still opens that graph and expands the group. This is an explicit entry alias, not a new screen or a duplicate canonical placement. Only the submenu entry has the current-page marker when UI-18 is selected. Workspace search can find Service dependencies by name.

At the revision-7 baseline there were 49 views. Alignment revision 22 retains this navigation behavior and adds nine customer-administration views, for 58 views across 13 primary destinations. The service-only graph, agent graph, APIs, SQL, objective extension boundary and readiness status are unchanged. Browser acceptance remains pending; source checks verify discovery and destinations.
