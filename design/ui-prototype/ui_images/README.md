# UACRF Core knowledge and agent interface images

Version 1.0 design revision 3 aligned to architecture revision 5. This set contains 33 images: all 25 earlier screens revised, plus eight new knowledge and agent workflows.

Open index.html for the searchable gallery, or SCREEN_REGISTER_v1_0.md to review each image. Keep this folder intact after extraction. The gallery is an image-review aid, not an operational UACRF application. No cloud connections, uploads, notifications, approvals or recoveries are performed by these images.

The new views cover the knowledge library, quarantined intake, human version review, grounded search, advisory-run setup, role and attempt progress, output and dissent review, and assistance settings. The existing screens now show where optional assistance belongs and which decisions remain under human and deterministic control.

The images use illustrative nonproduction data. Knowledge approval is distinct from operational evidence qualification. A2 assistance cannot automatically select operational proposals, approve or execute actions, or confirm recovery. Earlier images and archives remain preserved separately.

Exact prompts are in IMAGE_PROMPTS_v1_0.json. Images were generated and edited with the built-in image-generation tool. MANIFEST_v1_0.json records image dimensions and checksums. UI_IMPLEMENTATION_CONTRACT_v1_0.md and EXPERIENCE_GUIDE_v1_0.md explain the intended interactions and their limits.
