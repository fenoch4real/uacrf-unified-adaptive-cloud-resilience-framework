# Sample data (NOT real telemetry)

Everything under this directory is synthetic and exists only so the UI and
integration tests can show a near-complete estate before real collectors are
accepted. Nothing here is provider inventory or accepted evidence, and nothing
may be used as proof of real system behavior. All of it is generated by Java
(module `sample-data-tools`); there is no other language in the tooling.

| Path | Purpose |
| --- | --- |
| `connections/sample-local-estate.json` | A `SAMPLE_LOCAL` connection, six source bindings and a delivery log, including deliberate faults |
| `connections/sample-multicloud-estate.json` | AWS-, Azure- and Google Cloud-shaped feeds ingested through a `SAMPLE_LOCAL` connection: provider-shaped metric payloads, paged inventory (`NextToken`, `$skipToken`, `nextPageToken`), throttling / permission-denied outages, metric gaps and deliberate faults, plus a per-provider capability matrix |
| `graph/sample-multicloud-graph.json` | A fictional "Meridian Retail" graph that uses all 58 node labels and all 55 relationship types of `design/technical-approach/data-dictionary`. Every record is `SYNTHETIC_FIXTURE`; Authorization, Execution and agent signature records are void or simulated so they can never be mistaken for executable permits |

The real AWS, Azure and GCP connection types stay `UNACCEPTED` and cannot be
bound; the multi-cloud fixture only imitates their payload shapes. Provider
capabilities are declared per provider and never treated as equivalent.

Each delivery carries an `expect` value (`ACCEPTED`, `DUPLICATE` or
`QUARANTINED:<reason>`) that the S03 integration tests assert after posting the
deliveries in order.

## Regenerating

The tests fail when a committed file differs from what the generators produce,
and validate the graph against the data dictionary (labels, relationship types,
required and common properties, snake_case, no persisted aliases, endpoint
roles, cardinality, uniqueness, tenant scope).

```
./mvnw -pl sample-data test                                  # verify
./mvnw -pl sample-data test -Duacrf.sample.regenerate=true   # rewrite the JSON
```
